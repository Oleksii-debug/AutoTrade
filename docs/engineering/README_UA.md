# AutoTrade — інженерний пакет

Дата: 22 вересня 2026 року. Для Олексія.

Почни з `AUTOTRADE_READING_EDITION.html`: це один файл для послідовного читання у браузері з NVDA. Є зміст, заголовки та таблиці. Первинні інженерні документи — файли 00–09 англійською. `08_WORK_PACKAGE_BANK.json` містить той самий банк 65 пакетів робіт у машинному форматі. Файли 10–13 — додаткова організація паралельної розробки та сталі промпти воркера й аудитора. Для читання HTML завантаж архів, розпакуй і відкрий цей файл у браузері; попередній перегляд Drive може показувати його як текст.

Основну англійську продуктову специфікацію на Drive оновлено в тому самому файлі: 12 точкових змін, усі 40 розділів збережено. DOCX в архіві — її копія на дату пакета.

Архітектура не прив’язана до припущення про реєстрацію в Україні чи Словаччині. Bybit, Kraken, WhiteBIT, Binance, Interactive Brokers та Alpaca залишаються у плані. Можливості перевіряються для фактично підключеного акаунта.

Основний вибір — LEAN як готова фінансова основа; навколо нього визначено незалежний ризик, повноваження, журнал і звірку виконання, навчання, пам’ять та спільний стан Windows/web. План містить окремі перевірки, які мають підтвердити цей вибір під час реалізації.

Це інженерна документація та план реалізації. AutoTrade ще не створено й не протестовано як програму. Вивчення вихідного коду не позначено як виконання тестів. Неперевірені ліцензії, сумісність, реальні API та доступність чітко винесено в пакети приймання.
