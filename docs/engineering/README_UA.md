# AutoTrade — узгоджений baseline

Дата: 22 вересня 2026 року. Попередні файли та ZIP збережені як історія.

Почни з `AUTOTRADE_READING_EDITION.html` у корені розпакованого архіву. У ньому є зміст і заголовки документів 00–16 для читання у браузері з NVDA. Первинні документи розміщено в `docs/engineering/`, банк 65 пакетів — `control/work-packages/bank.json`, продуктова специфікація — `docs/product/`.

GitHub: https://github.com/Oleksii-debug/AutoTrade . Для продовження розробки відкрий `control/INDEX.json`, потім документ 15. Репозиторій уже містить початкові схеми, перенесені утиліти та контрольні тести; створювати це повторно не потрібно. Документ 16 описує виправлення, фактичні перевірки та залишкові обмеження.

Ревізію саме цього архіву містить `SOURCE_REVISION.json`. Перевірка: `python tools/baseline.py verify --archive <шлях-до-zip>` з checkout репозиторію. SHA manifest перевіряє цілісність, але не є цифровим підписом. Знімок registry в архіві не надає права займати пакети робіт.

Усі шість провайдерів залишаються у плані. Реєстрація в Україні або Словаччині не визначає архітектуру; можливості встановлюються для фактично підключеного акаунта.

Інженерний bootstrap уже існує. Фінансовий runtime, підключення провайдерів, повна доступність Windows/NVDA та реліз ще потребують реалізації і перевірки. Прибутковість не доведена.
