Overview

Getting started and recovering safely

  1. Open Accounts and host and check host, account, environment and freshness. No provider credentials are necessary for the ZERO/SIMULATION workflow.
  2. Review Opportunities and decisions, Portfolio and orders and Risk and authority. Host projections are evidence, not trading instructions.
  3. Use only host-backed controls for any permitted action. A command acceptance is not an executed fill; check the reported operation status and uncertainty.
  4. For an outage or restart, use Refresh host state and inspect History and diagnostics. The native Windows emergency block is independent of the WebView.
